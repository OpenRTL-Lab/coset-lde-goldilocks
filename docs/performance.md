# 性能指标

[English](performance.en.md)

典型65536点输入、4倍扩展的两种模式均通过32任务完整输出比对，500 MHz换算下达到152.512或181.577任务/秒；本文件分别定义任务延迟、实测稳态吞吐及有效运算忙率，并提供复现方法和逐项结果。

每任务输入 N=2^logN 个，按 B=2^logB 倍扩展输出 M=N×B 个。求值输入模式0先经 INTT 恢复系数，系数输入模式1跳过 INTT；之后均做陪集幂缩放、补零和 M 点 NTT。下列频率换算不是板级或硅后实测。

## 测试配置与定义

生成容量`maxLogM=18`，任务`logN=16, logB=2`，即 $N=65536$、$M=262144$，单蝶形通道。正向/逆向旋转因子预先装载一次；该初始化不计入单任务延迟。数据接口在可传输时持续供数，输出与完成接口持续就绪。存储使用实际RTL一拍同步读模型，不外加系统带宽或延迟约束。

任务接受上升沿为 $A_i$，最后输出接受沿为 $O_i$，完成消息接受沿为 $C_i$。任务延迟 $L_i=C_i-A_i$，包含输入装载、算术、幂链初始化、补零、同步读、流水填充/排空、输出及完成握手。

每个模式连续提交32个任务；稳态窗口取第2个到第30个任务的完成沿，共28个完成间隔。吞吐率 $T=28/(C_{30}-C_2)$，单位任务/拍。任务启动间隔从连续真实接受沿差值测量，另行核对完成间隔；并非简单用延迟倒数代替。换算任务/秒为 $fT$，延迟秒数为 $L/f$；本表 $f=500\times10^6$ Hz，依据 [综合结果](synthesis-summary.md)的通过频率。

## 计算单元与忙率

主模乘由四个并行32×32部分积、分块加法、Goldilocks约简流水构成，延迟18拍；蝶形含模加、模减及逆向归一化，延迟28拍。每拍有效发射计一次真实工作，不把无效拍上的寄存器翻转算作有效计算。流水占用另外按验证层中18拍有效历史统计，不与有效发射忙率混用。

计算阶段时长为逆/正NTT、种子生成、首次缩放读、系数/幂链缩放和缩放排空的阶段时长之和，不包含输入装载、补零、输出。主模乘及其四个部分积共享上述有效发射数量，不应算成四个独立吞吐通道。蝶形在NTT段两个结果都使用；系数/幂更新段复用蝶形首结果 `out0`，不把未使用的第二结果 `out1` 计作有用结果。

## 如何复现

两条大任务命令分别测模式0/1，`results.json`记录逐任务接受/输出/完成时间、有效工作、阶段、存储次数和聚合指标。完整命令见 [快速复现](reproduction.md)，统计实现见 [性能统计工具](../tools/metrics.py)。性能结果来自理想接口测试；协议背压和复位属于单独的功能测试，不混入性能数字。所有计数器位于绑定验证层，不进入产品文件清单。
